MyDock —— 贴边自动隐藏的快捷方式栏
==========================================

一、它是什么
------------
一个独立运行的小程序（不依赖 Wallpaper Engine，换壁纸也不影响）。
平时完全隐身；鼠标碰到屏幕边缘那条窄热区，先滑出一根白色小胶囊（白条）；
再把鼠标往屏幕里挪一点，图标面板才从白条后面滑出来。移开约半秒到 0.7 秒自动收回。

二、两层自动隐藏（白条 / 图标分开）
----------------------------------
1. 白条层：鼠标贴近屏幕边缘（约 18 像素内、且在这条栏的长度范围内）就显示白条；
   离开约 0.55 秒后白条自己收回去。白条也可以单独出现、单独隐藏，和图标互不影响。
2. 图标层：鼠标再往屏幕里挪（越过白条 + 空隙，约 24 像素处起）才展开图标面板；
   离开约 0.7 秒收回。
3. 两段互不打扰：图标展开时白条默认不显示，只有把鼠标移到白条所在的窄条位置，
   白条才单独淡入（方便右键进设置），和图标之间留 14 像素空隙。
4. 白条比之前更粗（10 像素），和图标分得清清楚楚。
5. 显隐都是淡入淡出 + 滑入滑出：图标 180 / 210 毫秒，白条 150 / 190 毫秒，
   滑动的边界就是白条所在的位置——收起时图标排压在白条那条线上，展开时从白条那儿滑出来
   （约 100 帧/秒驱动），所以没有拉伸、没有撕裂。
6. 鼠标指向哪颗图标，那一带就连续过渡地放大（最多到图标的 1.4 倍），
   鼠标滑过时放大效果跟着走，不会串到别的图标上，也不压邻居。

三、基本操作
------------
1. 拖动整栏：按住白条拖动，可以把它挪到屏幕任意位置；
   靠近左/右/上/下边缘（36 像素内）自动吸附，并自动变成竖排或横排；
   拖到某条边的中段（离正中 110 像素内）会自动居中吸附；
   停在屏幕中间即自由悬浮，此时白条和图标常驻不隐藏。
2. 换图标顺序：直接用鼠标把图标拖到另一个位置（拖到哪儿都能看见放大后的图标跟着鼠标走，
   松手自动回格），松手即保存顺序。
3. 启动程序：单击图标；鼠标停在图标上会浮出一个小黑条显示它的名字。
4. 加东西：把桌面上的 .lnk / 程序 / 文件夹拖到图标面板上（拖到白条上也行），松手就加进去了；
   文件夹会显示成黄色的文件夹图标，点开就是那个目录。也可以拖进设置窗口的图标列表。
5. 双击白条：直接打开“桌面图标”文件夹（就是设置里那个桌面目录），方便随手往里面丢新图标。
   双击时不会触发拖动，即使“锁定位置”也照样能双击打开。
6. 右键：在白条上、或者图标底下那块底卡上右键，都弹出本程序菜单
   （桌面 / 锁定位置 / 设置… / 退出）；只有点在真正的透明空白处才会穿透给桌面，
   弹的是 Windows 自己的桌面右键菜单（壁纸软件除外，本程序永远压在壁纸之上、普通窗口之下）。
   菜单本体也是自绘的，配色跟随系统浅色/深色主题。
   · 桌面：打开“桌面”文件夹（设置里那个桌面目录），方便随时加图标。
   · 锁定位置：锁定后白条不能再拖，图标顺序仍然可以拖。
   · 设置面板打开时会自动跳到最前面，但不会一直盖在最上面，被别的窗口压住会正常退到后面。

四、设置窗口
------------
右键菜单里选“设置…（图标与外观）”。窗口配色跟着“背景”那一项走：黑色→深色界面，白色→浅色界面，
跟随系统→看 Windows 的浅色/深色，与透明度多少无关；“选择文件夹 / 添加桌面图标”弹出的系统对话框，
标题栏也会跟随 Windows 的主题色。
窗口里所有改动都会**立刻**预览到快捷栏，点“确定”才保存，点“取消”全部还原。

  图标大小    32 ~ 100 像素的滑条（右边实时显示像素值）
  背景        黑色 / 白色 / 跟随系统（默认白色）；
              底卡只包住图标那一排，白条独立待在底卡外面
  透明度      50% ~ 100% 的滑条（1% 一档），只作用在图标后面那块底卡（图标和白条不受影响）：
              先勾选“应用透明度”才按滑条生效：50% 偏实，越大越透，100% = 完全不显示背景；
              取消勾选 = 纯色背景（完全不透明，只剩背景色）
  白条长度    滑条显示的是“达到当前上限的百分比”，拉到最右永远显示 100%；
              上限跟着图标数量和尺寸自动变——100% 时白条正好和最外那颗图标的边缘齐平，不会伸出去
  图标间距    0 ~ 24 像素的滑条
  开机自动启动 勾选框（菜单里不再有这一项）
  桌面目录    可直接改路径；“选择文件夹”按钮挑一个目录，换电脑时改这里就行
  添加桌面图标 从桌面目录里挑图标（可多选）加进快捷栏
  图标列表    只列出“已经在快捷栏里”的图标，顺序就是显示顺序
              像文件夹一样：双击“名字” = 删除该项；双击列表空白处 = 打开上面的桌面图标文件夹。选中后按 Delete 也可以删
              列表右侧不再有任何滚动条（原生和自绘的都去掉了），直接用滚轮上下翻，一格两行，滚到头就停
              也能把桌面上的 .lnk / 程序 / 文件夹直接拖进列表
  全选 / 删除 / 上移 / 下移：批量选择、批量删除、调整顺序
  注：图标列表里双击删除、拖文件进来这些操作，跟直接拖到快捷栏上的效果一样

  ★ 确定：写入 dock.ini，并按新清单整理 items 文件夹（缺的补上、多的删掉）
  ★ 取消：大小/背景/白条/目录/图标清单全部恢复成打开前的样子

五、文件说明（都在本程序所在文件夹里）
--------------------------------------
MyDock.exe      主程序（双击即用，可放任意目录）
dock.ini        配置：吸附边、位置、长度比、图标大小、间距、背景样式(bgstyle)、背景透明度(alpha)、桌面目录
items\          快捷栏里的图标（.lnk 快捷方式）+ order.txt 记录显示顺序
dock.log        运行日志，出问题时可以看最后几行

换到别的电脑：把整个文件夹拷过去，在设置里把“桌面目录”改成那台电脑的桌面即可
（一般就是 C:\Users\你的用户名\Desktop）。

六、小提示
----------
· 图标统一渲染成圆形（颜色取自图标自身的平均色），整窗都是逐像素透明合成，
  四角平滑、不带黑边、没有锯齿。图标按“放大后的尺寸”烘焙，悬停放大时是 1:1 贴图，
  放大过程中也不会发虚。
· 底卡的玻璃高光做了抖动处理：深色、半透明时不会出现一层层灰白“阶梯”，过渡是连续的。
· 透明度滑条、图标大小、白条长度、间距都是边拖边生效，不用松手。
· 拖进来的文件夹会变成真正的黄文件夹图标，图标上悬停会显示名字，和别的图标一眼能分开。
· 全屏程序（游戏、全屏视频）在前台时，白条和图标都会自动锁定，不会被误呼出；
  退出全屏后恢复。
· 想让它随开机启动：设置里勾上“开机自动启动”。
· 想彻底退出：菜单里选“退出”。
